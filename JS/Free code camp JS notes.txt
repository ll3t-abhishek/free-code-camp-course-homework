html drops whitespaces at ends (trailing whitespaces) there's no pixel for a "space" to occupy right before the tag ends.
textContent → reads the source → gives you "Previous entries : " (space included) ✅
innerText → asks "what does this look like rendered?" → the browser says "that trailing space isn't visible" → gives you "Previous entries :" (space gone) ❌

if you care about exact characters (including whitespace) as written in your HTML, use textContent. Use innerText only when you specifically want the "what a human would see" version — e.g. skipping over content hidden by display: none.

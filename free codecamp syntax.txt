	When using target="_blank", it's good practice to also add rel="noopener noreferrer" for security reasons:
	You can wrap more than just text: An <a> tag can wrap around images, <div>s, or entire cards, making the whole block clickable:

    src set?? renders different size of images on different types of screen
	srcset="cat-400w.jpg 400w, cat-800w.jpg 800w, cat-1200w.jpg 1200w"
	Each entry is: filename + a space + a width descriptor (400w means "this image is 400 pixels wide")
	example
	<img 
	  src="cat-800w.jpg"
	  srcset="cat-400w.jpg 400w, cat-800w.jpg 800w, cat-1200w.jpg 1200w"
	  sizes="(max-width: 600px) 100vw, 50vw"
	  alt="A fluffy orange cat"
	>
	This sizes value says: "if the screen is 600px or narrower, the image will take up 100% of the viewport width; otherwise, it'll take up 50% of the viewport width." The browser uses this info + srcset to calculate the ideal file to download.

<button></button>
	<a> vs <button> — knowing which to use: This trips up a lot of beginners.
	Use <a> when the user is navigating somewhere (a new page, a section, a file).
	Use <button> when the user is triggering an action (submitting a form, opening a modal, toggling something, running JavaScript).
	
	<button type="button">Just a button, does nothing on its own</button>
	<button type="submit">Submits the form</button>
	<button type="reset">Clears the form fields</button>
	It can contain more than just text — images, icons, etc:
		<button>
		  <img src="icon.svg" alt=""> Save Changes
		</button>
		
			
	Inside a <form>, if you don't specify type, it defaults to type="submit"
